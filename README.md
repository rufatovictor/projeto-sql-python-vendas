# Python e SQL - Vendas 

Projeto envolvendo SQL e Python utilizando a base de dados de uma empresa fictícia. 

## Objetivo do projeto

Esse projeto usa uma base de vendas de uma empresa fictícia, na qual o gestor faz solicitações para serem entregues em um arquivo final tratado. Os dados foram processados usando a linguagem python em conjunto com SQL.

## Tecnologias utilizadas

- Python
- SQL
- CSV
- GitHub

## Fonte de dados 

O dataset utilizado é fictício e contém dados de vendas de uma empresa.
